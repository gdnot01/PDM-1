## Descrição do projeto
Este projeto consiste na criação de um aplicativo mobile de loja virtual, com base em um tema sorteado pelo professor (Loja de Avatares Digitais). Desenvolvido para atender aos requisitos da Prova 2 da disciplina de Programação para Dispositivos Móveis 1 da Fundação Matias Machline requisitado pelo Professor Gabriel de Oliveira Araújo.

### Ferramenta usadas para desenvolvimento:
- React Native com Expo
- Expo Router (com Stack e Tabs Navigation)
- Componentização funcional com TSX
- Gerenciamento de estados e props
- Estilização com StyleSheet para React Native
- Servidor local simulado para produtos
- Git-Github para versionamento
- VScode
